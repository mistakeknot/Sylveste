## Refuted hypothesis (negative result, retained for the record)

The charter's P1 severity_example — "running the documented sync command
re-materializes 39 deleted files over the living corpus" — is REFUTED for the
current code: both sync engines guard with `SKIP:not-present-locally`
(sync-upstreams.sh:314-317, clavain_sync/classify.py:60-61) before any
`mkdir -p`/`cp` path is reachable, and the weekly CI (sync.yml) runs the same
guarded engine. The 39/65 dead catalog targets are real (verified on disk),
but they manifest as an un-shrinkable catalog and silent fossil retention
(findings 1 and 8 above), not as resurrection.
